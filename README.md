# TripKIRA website (GitHub Pages)

Static public marketing website. No private member data or credentials.

## Publish
1. Create repository `tripkira-main` under `tripskira` if it does not exist.
2. Upload `index.html`, `styles.css`, `.nojekyll`, and the complete `assets/` folder to repository root.
3. Repository Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
4. Open https://tripskira.github.io/tripkira-main/ after publishing.

## Before launch
- Replace the registration placeholder with a real verified signup endpoint.
- Review actual programme terms, privacy notice, and app links.
- Add secure server-side authentication before exposing driver dashboards, membership IDs or private PDFs.
- Keep Google Sheet credentials, tokens and private data out of this public repository.
